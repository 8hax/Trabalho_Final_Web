# Screenshots

Salve os prints com **estes nomes** (são os referenciados no `README.md` da raiz):

| Arquivo | O que capturar |
| --- | --- |
| `board.png` | A página `/tech` com a lista de threads |
| `thread.png` | Uma thread com posts e respostas `>>` (quote-links / backlinks) |
| `login.png` | A tela de login (ou cadastro) |
| `admin.png` | O painel `/admin` (toggle da IA + gerar posts) |
| `perfil.png` | A página `/perfil` (editar perfil / trocar senha) |

Formatos: PNG ou JPG. Podem usar menos imagens — é só remover as linhas
correspondentes na seção **Screenshots** do README da raiz.
